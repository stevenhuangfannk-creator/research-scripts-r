# 原创可复用矢量组件

[components.R](components.R) 包含 `cell_circle`／`immune_cell`／`fibroblast`／`epithelial` 细胞形状，以及血管、箭头、受体配体、DNA、RNA、细胞因子和通路节点 grob。使用登记的命名颜色，在 grid viewport 中组合。

[组件预览](gallery/schematic_components_v1.png)由 `scripts/generate_gallery.R` 生成，同时有[可编辑 PDF](gallery/schematic_components_v1.pdf)与 [SVG](gallery/schematic_components_v1.svg)。没有使用下载图标或受保护期刊图稿。
