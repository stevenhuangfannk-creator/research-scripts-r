# Original reusable vector components

[components.R](components.R) contains cell_circle/immune_cell/fibroblast/epithelial cell shapes,
vessel, arrow, receptor_ligand, DNA, RNA, cytokine and pathway_node grobs. Choose named registry
colors and compose inside grid viewports. The [component sheet](gallery/schematic_components_v1.png)
is generated by scripts/generate_gallery.R, with [editable PDF](gallery/schematic_components_v1.pdf)
and [SVG](gallery/schematic_components_v1.svg). No downloaded icons or protected journal figures.
