# 基因网络（06_gene_networks）

PPI 蛋白互作、共表达模块和转录因子调控子（regulon）是不同网络，应先根据科研问题选择。

| 问题 | 方法入口 | 当前可用范围 |
|---|---|---|
| 已有蛋白互作证据，想找网络枢纽 | [PPI](PPI/README.md) | CANDIDATE；方法卡与规划 |
| 独立样本之间的共表达模块 | [WGCNA](WGCNA/README.md) | CANDIDATE；方法卡与规划 |
| 明确单细胞聚合设计后的共表达 | [hdWGCNA](hdWGCNA/README.md) | CANDIDATE；方法卡与规划 |
| 候选转录因子—靶基因调控子 | [SCENIC](SCENIC/README.md) | CANDIDATE；方法卡与规划 |

这四个方法尚无可执行工作流；目录和已安装的包不能作为分析成功的证据。先读[方法索引](../METHOD_INDEX.md)、[全局图例](../GALLERY.md)和[注册表说明](../registry/README.md)，再核对输入、参数与验证范围。
